# Contributing Guidelines

## Code Style
- Use clear and descriptive names for variables and functions.
- Indent with 4 spaces.
- Comment complex parts of the code.

## Pull Requests
1. Create a branch from `main` (e.g. `feature/1-name`).
2. Make your changes and commit with clear messages.
3. Open a pull request and reference the issue (e.g. "Resolves #1").

## Reporting Issues
- Check that the issue doesn't already exist.
- Use a clear title and describe the problem.
- Include steps to reproduce it.
